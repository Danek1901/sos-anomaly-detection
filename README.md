# SoS Anomaly Detection

Проект на Python для поиска аномально высокой активности респондентов в данных **Share of Search (SoS)**.

Задача решения — определить случаи, когда активность одного респондента в конкретный день непропорционально сильно влияет на OTS бренда внутри категории, и сформировать список наблюдений для очистки.

## Стек

- Python
- Pandas
- NumPy
- Matplotlib
- статистический анализ данных

## Что делает решение

1. Загружает исходные данные из папки `data_train/` или архива `data_train.zip`.
2. Оставляет строки, входящие в поставку SoS: `BrandinDelivery = 1`.
3. Рассчитывает дневной OTS на уровне:

```text
SubjectID + researchdate + BrandID + CategoryDelivery
```

4. Ищет аномально высокие значения `daily_ots` с помощью статистического порога внутри каждой категории.
5. Формирует список пар `SubjectID + researchdate` для исключения.
6. Сохраняет подробное объяснение каждой найденной аномалии.
7. Строит графики для сравнения данных до и после очистки.

## Результат тестового запуска

```text
Найдено триггеров аномалий: 178
Удаляемых пар SubjectID-date: 165
Доля удаляемых respondent-day: 0.1211%
Сохранено OTS после очистки: 96.31%
```

## Запуск

```bash
pip install -r requirements.txt
python solution.py
```

Если данные находятся в ZIP-архиве:

```bash
python solution.py --data data_train.zip
```

После запуска результаты сохраняются в папку `output/`.

## Как определяется аномалия

Алгоритм не использует заранее заданные идентификаторы респондентов, даты, бренды или фиксированный процент удалений. Порог рассчитывается по данным отдельно для каждой категории.

Для каждой найденной аномалии сохраняются диагностические значения, включая `daily_ots`, `score`, `threshold` и причину срабатывания.

Подробное описание алгоритма: [algorithm_description.md](algorithm_description.md).
